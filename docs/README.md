# Notion-Spiegel

Dieser Ordner ist eine Momentaufnahme der wichtigsten Notion-Seiten aus dem
Space "Sicura Website Relaunch", Stand 30.08.2026. Er existiert, damit
Claude Code auch ohne Notion-Zugriff arbeiten kann (siehe `CLAUDE.md`).

**Notion bleibt die Quelle der Wahrheit.** Bei Widerspruch zwischen diesem
Ordner und dem aktuellen Notion-Stand gilt Notion. Vorrangreihenfolge laut
Notion "00 – START HERE": 17 → 16 → 14 → 18 → 19 → 13 → alles andere.

| Datei | Notion-Seite | Enthält |
|---|---|---|
| `17-kundenbriefing-kompakt.md` | 17 | Alle Fakten, Negativliste, verbindliche Formulierungen, offene Punkte |
| `14-sitemap.md` | 14 | Verbindliche Seitenliste, Navigation, Redirect-Map |
| `18-designsystem.md` | 18 | Farb-, Typo-, Abstands-Tokens, Komponenten, Abnahmekriterien |
| `19-seitentexte.md` | 19 | Freigegebene Textentwürfe für alle 11 Seiten |

Für Rechtstexte (Notion 08), Sicherheitskonzept (Notion 07) und die volle
Alt-URL-Liste (Notion 03) direkt in Notion nachschlagen — diese wurden nicht
gespiegelt, weil sie sich mit rechtlicher Prüfung bzw. Serverzugängen ändern.
